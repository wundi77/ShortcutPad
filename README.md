# ShortcutPad

Touch-Buttons auf iPhone/iPad (App oder Webseite) lösen Tastaturkürzel im gerade aktiven Mac-Programm aus.
Die Kürzel-Sets werden ausschließlich in der Mac-App verwaltet.
